# RTK Global

Global Relay Task Kernel rules, shared by every project on this machine.

Projects add a thin overlay in their own `.rtk/`. Do not copy this directory
into a repository.

## Layout

- `RTK.md` - entry point, load order, core contract
- `rules/` - behaviour rules
- `templates/` - task, context, memory and handoff formats
- `schemas/` - machine-readable Task Packet schema

## Safety

Never store secrets, tokens, credentials, or private project identifiers in
RTK files. These files are read by agents and frequently pasted into logs.

Generated by [relay-task-kernel](https://github.com/leavemagic-cyber/relay-task-kernel).
Re-run `rtk init --global` to update; edits outside the `RTK:BEGIN/END`
markers are preserved.
